# DonateConnect Frontend (React 18 + Vite + TypeScript)

Web application frontend for DonateConnect built with React 18, Vite, TypeScript, Axios, React Router DOM, and React Hook Form.

## Local Setup

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open browser at [http://localhost:5173](http://localhost:5173).
